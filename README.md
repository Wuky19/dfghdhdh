# HAATZ(하츠) 웹사이트 리뉴얼

## 프로젝트 소개
하츠(HAATZ)의 브랜드와 제품 정보를 효과적으로 전달하고, 사용자가 주요 콘텐츠를 편리하게 탐색할 수 있도록 제작한 웹사이트 리뉴얼 프로젝트입니다. HTML, CSS, JavaScript를 활용해 페이지 구조와 디자인을 구성하고, 메뉴 및 스크롤 기반 인터랙션을 적용했습니다.

## 주요 기능

### 1. 메가 메뉴
- 주요 메뉴의 하위 항목을 한눈에 확인할 수 있도록 메가 메뉴 구성
- 마우스 및 키보드 사용을 고려한 메뉴 인터랙션

### 2. 하츠 이야기 영역
- 사진을 활용한 브랜드 소개 영역 구성
- 스크롤에 반응하는 배경 이미지 효과 적용
- 제목과 설명 등 콘텐츠 등장 효과 적용

### 3. 스크롤 인터랙션
- 콘텐츠가 화면에 들어올 때 등장 효과 적용
- `prefers-reduced-motion` 설정을 고려해 움직임을 줄이는 환경 지원

### 4. 제품 및 콘텐츠
- 제품과 서비스 정보를 탐색할 수 있도록 콘텐츠 구성
- 대표 제품 설명과 푸터 콘텐츠 정리

## 기술 스택
- **HTML5** — 콘텐츠 구조와 시맨틱 마크업
- **CSS3** — 레이아웃, 반응형 스타일, 전환 및 애니메이션
- **JavaScript** — 메뉴 동작과 스크롤 인터랙션

## 실행 및 확인 방법
1. 저장소를 내려받거나 복제합니다.
2. `haatz_renewal/index.html`을 브라우저에서 열거나 VS Code의 Live Server로 실행합니다.
3. 메뉴 동작, 스크롤 효과, 이미지 표시를 확인합니다.
4. 모바일을 포함한 다양한 화면 너비에서도 레이아웃이 자연스러운지 확인합니다.

## 참고 사항
- 이미지 파일은 `haatz_renewal/img/` 폴더에 저장합니다.
- HTML과 CSS에서 사용하는 이미지 경로 및 파일명은 실제 `img/` 폴더의 구조와 일치해야 합니다.
- 이 README는 프로젝트 설명용 문서이며, 실제 배포 상태와 인터랙션은 브라우저에서 별도로 테스트해야 합니다.
